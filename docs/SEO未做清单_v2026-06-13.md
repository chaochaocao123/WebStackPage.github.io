## 二、未做清单（按价值/难度分级）

### 🔴 P0 — 高价值，必须做

#### 1. 动态 OG image 路由（**高价值 / 中难度**）
- **现状**：所有页面 OG image 指向静态 `/og-image.png`
- **问题**：分享到微信/微博/小红书/LinkedIn 时**千人一面**，CTR 弱
- **方案**：`app/og/[type]/[id]/route.tsx` 用 `@vercel/og` 渲染 JSX
  - news：`[类型标识] + 标题 + 来源 + 品牌色块`
  - article：`[文章] + 标题 + 作者 + 标签条`
  - tool：`[工具] + 名称 + Logo + 优惠价`
- **收益**：SERP 分享卡片点击率 ↑ 30-50%
- **工作量**：半天（含测试 3 类页面）
- **依赖**：`@vercel/og`（可能需要新装依赖，Vercel Hobby 免费额度内）

#### 2. Tool 详情页 `/tools/[slug]`（**高价值 / 中难度**）
- **现状**：`/tools` 列表页，但**没有详情页**；sitemap.ts 已注释 `// 计划：v8 加 tool 详情页`
- **问题**：70+ 工具详情页 0 详情，**长尾关键词（"卖家精灵评测" "Helium10 优惠码"）严重浪费**
- **方案**：
  - 新建 `app/tools/[slug]/page.tsx`
  - generateMetadata：title/desc/keywords/OG（含 logo 图）
  - JSON-LD：Product（工具名 + 评分 + 优惠 + 联盟链接）
  - 内容：功能介绍 / 优惠详情 / 用户评价 / 相关工具
  - 启用 sitemap Tool 路由
- **收益**：长尾搜索流量 ×3-5 倍（估 1000+ 长尾词）
- **工作量**：1-2 天（含 70 个工具 schema 适配）

#### 3. Deal 详情页 `/deals/[id]`（**高价值 / 中难度**）
- **现状**：sitemap.ts 注释 `// v9 加 deal 详情页`
- **方案**：同 Tool 详情页结构，联盟链接外跳前做中转页（防外链权重流失 + 转化埋点）
- **收益**：优惠长尾词覆盖
- **工作量**：1 天

#### 4. 站长工具验证文件（**基础 / 低难度**）
- **现状**：`public/` 下**无**任何验证文件
- **缺**：
  - `public/baidu-verify-XXX.html`（百度站长平台）
  - `public/BingSiteAuth.xml`（Bing Webmaster）
  - `public/google-XXX.html`（Google Search Console）
  - `public/sogou-verify-XXX.txt`（搜狗站长）
- **收益**：所有站长工具诊断/收录 API 都依赖这个
- **工作量**：10 分钟（需要曹总去各平台申请验证串后填入）

### 🟡 P1 — 中价值，建议做

#### 5. FAQ Schema（**中价值 / 低难度**）
- **现状**：所有页面**无** FAQPage JSON-LD
- **方案**：
  - 工具详情页：5-8 条常见问题（"多少钱""免费吗""支持哪些平台"）
  - 首页：跨境电商入门问答
  - articles：文章内 H2 改写为 FAQ
- **收益**：富媒体结果直接展示问答（占 SERP 一整屏）
- **工作量**：半天

#### 6. 内链 / 锚文本优化（**中价值 / 低难度**）
- **现状**：articles 详情页**无**"相关文章"、news 详情页**无**"相关工具"
- **方案**：
  - `app/articles/[slug]/page.tsx` 底部加 3 条同 tag 文章
  - `app/news/[id]/page.tsx` 底部加 3 条同分类工具（自动关联）
- **收益**：爬虫深度+权重传递+用户停留时长 ↑
- **工作量**：2-3 小时

#### 7. 安全头（**中价值 / 低难度**）
- **现状**：`middleware.ts` 只配缓存头，**无**安全头
- **加**：
  ```
  Strict-Transport-Security: max-age=63072000
  X-Frame-Options: SAMEORIGIN
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=()
  ```
- **收益**：信任度 + Google 排名因子（2024 起 HTTPS-only 加分）
- **工作量**：1 小时

#### 8. E-E-A-T 基础页（**中价值 / 低难度**）
- **现状**：`/about` `/privacy` `/terms` `/contact` **全部缺失**
- **方案**：4 个静态页 + 顶层 Footer 链接
- **收益**：Google E-E-A-T 评分（特别是 YMYL 类站点）
- **工作量**：半天（写 4 页文案 + 接入 layout）

#### 9. Google Search Console 接入（**中价值 / 低难度**）
- **现状**：自研埋点 `/api/track` 替代了 GA，**Search Console 完全未接**
- **方案**：验证文件 + 提交 sitemap + 用 `next/script` 集成 GSC 验证 meta
- **收益**：索引覆盖率、关键词排名、移动可用性诊断
- **工作量**：1 小时
